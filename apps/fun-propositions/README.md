# 재미있는 명제들

첨부 문서 「참일까, 거짓일까? 재미있는 수학 명제 12선」을 바탕으로 만든 별도 정적 웹앱입니다. 기존 Research-on-Common-Mathematics2의 라우트·데이터·배포 설정과 연결하지 않았습니다.

## 사용 흐름

- 총 15개를 PART 01 간단한 명제(01~~05), PART 02 조금 더 멀리, 수학의 확장(06~~14), PART 03 특별 탐구(15)로 나눠 탐색합니다.
- 참·거짓을 예상한 뒤 판정, 원문의 조건과 전체 풀이, 단원 연결, 추가 질문을 확인합니다.
- 소수 공식과 홀수의 합, 자릿수 뒤집기를 조작할 수 있습니다.
- 화면에는 현재 순서대로 01~15를 연속 표시합니다. 원고 식별번호와 기존 상세 링크는 유지하며, 원고 기준 05·15·16·17·18은 웹앱에서 제외합니다. 이전/다음 이동은 남은 명제만 순서대로 연결합니다.
- 화면 번호 12·13·14·15에는 결론에서 거꾸로 근거를 찾는 발문과 정방향 증명 확인을 제공합니다. 남은 명제의 본문과 활동은 유지합니다.
- 이발사의 역설은 별도 파트로, 자신을 깎는 경우·깎지 않는 경우·그런 이발사는 없다는 세 예상을 비교합니다. 규칙의 양방향 조건과 이발사 자신이 대상에 포함됨을 명시하고, 존재 명제가 거짓임을 설명합니다.
- 예상 답과 열어 본 명제는 현재 페이지 세션에서만 기억하며 새로고침하면 초기화됩니다.

## 독립 실행

Node.js 22.13 이상에서 이 폴더를 기준으로 실행합니다.

```sh
npm ci
npm run dev
```

기본 미리보기 주소는 `http://localhost:4174`입니다. `PORT` 환경변수로 포트를 바꿀 수 있습니다. 소스 수정 후에는 `npm run build`를 실행하고 브라우저를 새로고침합니다.

```sh
npm run check
npm run build
npm run preview
```

`dist/` 전체가 독립 배포 산출물입니다. HTML, 자바스크립트, CSS, 수식 및 수식 글꼴을 포함하고 외부 CDN이나 기존 사이트 실행 서버가 필요하지 않습니다. 정적 호스팅의 게시 디렉터리는 `dist`이며, 해시를 이용해 이동하므로 별도 경로 재작성 설정이 필요 없습니다.

## 원문과 후속 연결

`content/propositions.md`에 제공된 원문을 그대로 보존합니다. 추가 원고는 `content/additional-propositions.md`에서 관리합니다. 빌드 시 `src/catalog.js`의 제외 번호를 제거한 15개만 앱 데이터로 내보냅니다. 제외한 원고는 참고 자료로만 보관하며 목록·상세 화면에 표시하지 않습니다. 원문의 지시는 앱 제작 명령으로 실행하지 않습니다.

다음 단계는 사용자가 요청하면 별도 앱을 배포한 후 실제 공개 주소를 기존 사이트의 명제 탭에 새 주제 「재미있는 명제들」로 연결하는 것입니다. 아직 공개 배포·기존 사이트 링크 추가·커밋·푸시는 하지 않았습니다.
